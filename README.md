# Yugiyu 요청 및 조회수 확인 프로그램

지정한 Yugiyu 상품 페이지에 여러 번 HTTP GET 요청을 보내고, 각 응답에서 조회수 영역을 찾아 현재 조회수를 출력하는 Python 프로그램입니다.

이 프로그램은 `curl` 명령을 직접 사용하는 방식이 아니라 Python의 `requests` 라이브러리를 사용합니다. 요청을 여러 작업으로 나누어 동시에 실행할 수 있으며, 실행에 필요한 URL과 요청 수는 `setting.ini`에서 관리합니다.

## 동작 원리

1. 프로그램을 실행하면 메뉴가 표시됩니다.
2. `1. 시작`을 선택하면 `setting.ini`를 읽습니다.
3. 설정된 요청 수만큼 작업을 만들고, `max_workers` 값만큼 동시에 실행합니다.
4. 각 작업은 독립적인 `requests.Session`으로 URL에 GET 요청을 보냅니다.
5. 응답 상태 코드가 오류이면 실패로 처리합니다.
6. 응답 HTML에서 조회수 영역을 찾아 숫자를 추출합니다.
7. 요청별 결과와 성공·실패 개수를 터미널에 출력합니다.

이 프로그램은 응답을 확인하는 용도로 동작하며, 로그인이나 별도의 POST 요청은 사용하지 않습니다. 대상 사이트의 이용약관과 요청 제한을 반드시 준수해야 합니다.

## 요구 사항

- Python 3.11 이상
- [uv](https://docs.astral.sh/uv/) Python 프로젝트 관리 도구
- 인터넷 연결

## 설치

프로젝트 폴더에서 실행합니다.

```powershell
uv sync
```

`uv sync`는 `pyproject.toml`과 `uv.lock`을 기준으로 가상환경을 만들고 `requests` 및 필요한 의존성을 설치합니다.

## 실행

```powershell
uv run main.py
```

메뉴에서 다음과 같이 선택합니다.

```text
1. 시작
2. 설정
0. 종료
```

실행 중 중지하려면 `Ctrl+C`를 누릅니다. 대기 중인 작업은 취소되며, 이미 실행 중인 요청은 `timeout` 설정에 따라 마무리될 수 있습니다.

## 설정

`setting.ini`는 다음 형식입니다.

```ini
[settings]
url = https://www.yugiyu5.com/mall/48
total_requests = 5000
max_workers = 5
timeout = 20
```

- `url`: 요청할 페이지 주소
- `total_requests`: 전체 요청 횟수
- `max_workers`: 동시에 실행할 요청 수
- `timeout`: 요청 하나의 최대 대기 시간(초)

프로그램 메뉴에서 `2. 설정`을 선택해도 같은 값을 입력하고 저장할 수 있습니다. 입력할 때 Enter만 누르면 기존 값이 유지됩니다.

## 프로젝트 구조

```text
.
├── main.py           # 메뉴, 설정 로딩, 요청 실행 코드
├── setting.ini       # 실행 설정
├── pyproject.toml    # 프로젝트 정보와 직접 의존성
├── uv.lock           # 고정된 의존성 버전
├── .python-version   # 사용할 Python 버전
└── README.md         # 이 문서
```

`.venv`는 컴퓨터마다 다시 생성되는 가상환경이므로 프로젝트를 옮길 때 복사하지 않아도 됩니다. 다른 컴퓨터에서는 프로젝트 파일을 가져온 뒤 `uv sync`를 실행하면 됩니다.

## 주의 사항

요청 수와 동시 실행 수를 크게 설정하면 대상 서버에 부하를 줄 수 있고, IP 차단이나 서비스 이용 제한이 발생할 수 있습니다. 본인이 관리하거나 명시적으로 허가받은 대상에 대해서만 낮은 요청량으로 사용하세요.
